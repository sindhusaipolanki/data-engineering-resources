## 2026-10-01 — SQL: Index foreign key columns in fact tables

Fact tables join to dimensions on foreign keys. Without indexes on those columns, every join does a full table scan. Add non-clustered indexes on all FK columns in your fact tables.

```sql
-- SQL Server / Azure SQL
CREATE NONCLUSTERED INDEX IX_fact_sales_customer
  ON dbo.fact_sales (customer_id)
  INCLUDE (amount, transaction_date);

CREATE NONCLUSTERED INDEX IX_fact_sales_product
  ON dbo.fact_sales (product_id)
  INCLUDE (amount, quantity);
```

## 2026-10-03 — Data Quality: Use Great Expectations for automated data contracts

Define data expectations as code — column types, value ranges, referential integrity. Run them in your pipeline as a quality gate. Failed expectations block the write and alert the team before bad data reaches consumers.

```python
import great_expectations as gx

context = gx.get_context()
suite = context.add_expectation_suite('silver.sales')
suite.add_expectation(
    gx.expectations.ExpectColumnValuesToBeBetween(
        column='amount', min_value=0, max_value=1_000_000
    )
)
```
