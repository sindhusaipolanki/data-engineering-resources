# Daily Data Engineering Tips — October 2026


## 2026-10-01 — SQL: Index foreign key columns in fact tables

Fact tables join to dimensions on foreign keys. Without indexes on those columns, every join does a full table scan. Add non-clustered indexes on all FK columns in your fact tables.

```sql
-- SQL Server / Azure SQL
CREATE NONCLUSTERED INDEX IX_fact_sales_customer
  ON dbo.fact_sales (customer_id)
  INCLUDE (amount, transaction_date);

CREATE NONCLUSTERED INDEX IX_fact_sales_product
  ON dbo.fact_sales (product_id)
  INCLUDE (amount, quantity);
```

## 2026-10-03 — Data Quality: Use Great Expectations for automated data contracts

Define data expectations as code — column types, value ranges, referential integrity. Run them in your pipeline as a quality gate. Failed expectations block the write and alert the team before bad data reaches consumers.

```python
import great_expectations as gx

context = gx.get_context()
suite = context.add_expectation_suite('silver.sales')
suite.add_expectation(
    gx.expectations.ExpectColumnValuesToBeBetween(
        column='amount', min_value=0, max_value=1_000_000
    )
)
```

## 2026-10-04 — PySpark: Use Adaptive Query Execution (AQE)

AQE dynamically re-optimizes queries at runtime based on actual partition statistics. Enable it globally — it automatically handles skew joins, coalesces shuffle partitions, and switches join strategies.

```python
spark = SparkSession.builder\
  .config('spark.sql.adaptive.enabled', 'true')\
  .config('spark.sql.adaptive.coalescePartitions.enabled', 'true')\
  .config('spark.sql.adaptive.skewJoin.enabled', 'true')\
  .getOrCreate()
```

## 2026-10-05 — Delta Lake: Enable Change Data Feed for incremental reads

Delta's Change Data Feed (CDF) tracks row-level inserts, updates, and deletes. Use it to propagate only changed records downstream instead of reprocessing entire tables.

```sql
-- Enable on existing table
ALTER TABLE silver.customers
SET TBLPROPERTIES ('delta.enableChangeDataFeed' = 'true');

-- Read changes since version 10
SELECT * FROM table_changes('silver.customers', 10)
WHERE _change_type IN ('insert', 'update_postimage');
```

## 2026-10-06 — SQL: Partition elimination is your best optimization

Filtering on a partition column eliminates entire file groups before reading. A query on a 10TB table with date partitioning might read only 27GB for a single month. Always design partition keys around your most common query patterns.

```sql
-- Table partitioned by year, month
-- This query reads ONLY 2024/01 partition files
SELECT SUM(amount)
FROM fact_sales
WHERE year = 2024 AND month = 1;
```

## 2026-10-07 — Azure Data Factory: Set retry policies on all Copy activities

Network blips and transient source errors cause pipelines to fail unnecessarily. Set retry count to 3 with 30-second intervals on all Copy activities. This handles most transient failures without manual intervention.

```python

  "retry": 3,
  "retryIntervalInSeconds": 30,
  "timeout": "02:00:00"
```

## 2026-10-08 — Data Quality: Reconcile row counts between source and target

After every load, compare row counts between source and destination. A mismatch signals a dropped partition, a failed partial write, or a filter bug. Log the delta and alert on >0.1% variance.

```python
def reconcile(source_count: int, target_count: int, table: str) -> None:
    delta = abs(source_count - target_count)
    pct = delta / source_count if source_count > 0 else 1.0
    if pct > 0.001:
        raise ValueError(
            f'{table}: source={source_count:,}, target={target_count:,}, '
            f'delta={delta:,} ({pct:.2%}) — exceeds 0.1% threshold'
        )
```
